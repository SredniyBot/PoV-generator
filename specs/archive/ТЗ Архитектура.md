# Архивный черновик архитектурного ТЗ

> Статус: архив. Документ сохранен только как исторический черновик и не должен использоваться как актуальная спецификация.

Актуальная архитектура проекта теперь разложена по активным документам в директории `specs/`.

Нормативные документы:

- `00_vision.md` - цель и продуктовая рамка;
- `01_architecture.md` - карта системы и компонентов;
- `02_registry_dsl.md` - YAML-модель реестра;
- `03_task_graph.md` - runtime-граф задач;
- `04_task_template_semantics.md` - семантика шаблонов задач;
- `05_problem_state.md` - состояние понимания проекта;
- `06_planning.md` - выбор и приоритизация задач;
- `07_execution_context.md` - контекст, исполнение и артефакты;
- `08_validation_governance.md` - проверки качества и эскалации;
- `09_domain_packs.md` - доменные расширения;
- `10_ui_workspace.md` - пользовательское рабочее пространство;
- `11_ui_realtime_api.md` - API и real-time синхронизация UI.

Если содержание этого файла противоречит активным спецификациям, верными считаются активные спецификации.
